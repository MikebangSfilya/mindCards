# mindCards

**mindCards** — это backend-сервис для создания карточек памяти (flashcards). Подходит для реализации методик интервального повторения. Карточка может содержать вопрос/ответ, термин/описание или любую другую пару данных.

## Структура карточки

Каждая карточка в базе данных состоит из:
1.  **ID**: Уникальный идентификатор.
2.  **Title**: Заголовок (вопрос или термин).
3.  **Description**: Описание (ответ или расшифровка).
4.  **Tag**: Тег для группировки (например, "Go", "English").
5.  **LevelStudy**: Уровень изученности (от 0 до 5).
6.  **Learned**: Флаг (bool), указывающий, что карточка полностью изучена.

## Как запустить

В проекте настроен `Makefile` для удобного управления.

### Предварительные требования
* Go 1.24+
* Docker & Docker Compose
* **golang-migrate** (утилита для миграций)
  * *Установка:* `go install -tags 'postgres' github.com/golang-migrate/migrate/v4/cmd/migrate@latest`

### Запуск локально (в Docker)

1.  Клонируйте репозиторий.
2.  Создайте конфигурационные файлы (можно скопировать примеры):
    ```bash
    cp config.example.yaml config.yaml
    cp .env.example .env
    ```
3.  Запустите контейнеры:
    ```bash
    make up
    ```
    Это поднимет приложение, PostgreSQL и Redis.
4.  Накатите миграции (создайте таблицы в БД):
    ```bash
    make migrate-up
    ```

Теперь сервис полностью готов к работе.

### Полезные команды
* `make up-infra` — поднять только базы (Postgres + Redis).
* `make run` — запустить Go-приложение локально (требует поднятой инфры).
* `make migrate-down` — откатить последнюю миграцию.
* `make test` — запустить unit-тесты.

## API Endpoints

Сервис работает на порту `8080`.
**Важно:** Для большинства запросов требуется заголовок `X-User-ID` (целое число > 0), имитирующий авторизацию.

### Пользователи

* **Регистрация**
  `POST /user`
    ```json
    {
        "email": "user@example.com",
        "password": "strongpassword"
    }
    ```
  *Пароли хешируются перед сохранением.*

### Карточки

Все запросы ниже требуют заголовок `X-User-ID: <id>`.

* **Получить все карточки** (с пагинацией)
  `GET /card?limit=50&offset=0`

* **Получить карточку по ID**
  `GET /card/{id}`
  *Примечание: Ответ кешируется в Redis на 24 часа.*

* **Получить карточки по тегу**
  `GET /card/tag/{tag}?limit=50&offset=0`

* **Добавить карточки** (принимает массив)
  `POST /card`
    ```json
    [
        {
            "title": "Interfaces",
            "description": "Набор сигнатур методов...",
            "tag": "Go"
        }
    ]
    ```

* **Обновить описание карточки**
  `PUT /card/{id}`
    ```json
    {
        "description": "Новое описание карточки"
    }
    ```
  *При обновлении кеш в Redis для этой карточки сбрасывается.*

* **Удалить карточку**
  `DELETE /card/{id}`
